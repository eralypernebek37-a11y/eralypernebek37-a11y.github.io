# Информатика 7-сынып — 2-тоқсан

## GitHub Pages-ке қою
1. GitHub-та жаңа репозиторий ашыңыз (Public).
2. Зипті ашып, **ішіндегі файлдарды** (папканы емес) жүктеңіз: `index.html`, `style.css`, `app.js`, `.nojekyll`, `videos/`.
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
4. 1–2 минуттан кейін сайт `https://АТЫҢЫЗ.github.io/РЕПО/` мекенжайында ашылады.

## Видео қосу
- MP4: `videos/lesson-1.mp4 … lesson-6.mp4` деп атап салыңыз (әр файл 100 МБ-тан кіші болсын).
- YouTube: `app.js` басындағы `const YT={}` жолына `{1:"VIDEO_ID",2:"..."}` деп жазыңыз.
- Видео жоқ болса, сайт «Видео жақында қосылады» деп көрсетеді.

## Жаңа сабақ қосу
`app.js` ішіндегі `L` массивіне бір блок қосыңыз — карточка, тізім және прогресс автоматты шығады.
