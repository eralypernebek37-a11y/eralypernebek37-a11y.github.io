# Информатика 7-сынып — 2-тоқсан

Интерактивті оқу платформасының бастапқы дайын нұсқасы.

## Іске қосу
`index.html` файлын браузерде ашыңыз.

## GitHub Pages
1. Осы папкадағы файлдарды GitHub репозиторийіне жүктеңіз.
2. Settings → Pages бөліміне кіріңіз.
3. Deploy from a branch → `main` / `(root)` таңдаңыз.
4. Save басыңыз.

## Видео қосу
`videos` папкасына:
- lesson-1.mp4
- lesson-2.mp4
- ...
- lesson-6.mp4

файлдарын орналастыруға болады. Қазіргі нұсқада видеосабаққа placeholder қойылған.

## Сабақтар
1. Мәтіндік процессордағы кестелер
2. Электронды кесте элементтерін пішімдеу
3. Мәліметтер пішімі
4. Шартты пішімдеу
5. Кестелі мәліметтердің графикалық ұсынылуы
6. Процестерді электронды кестелерде модельдеу

Прогресс браузердің localStorage жадында сақталады.
